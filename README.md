# barathkrishna.com

Static site. No build step. GitHub Pages serves this folder as-is.

- `index.html` — the page (template + logic)
- `content.js` — all copy: projects, experience, education, skills. Edit here to update the site.
- `media/` — project videos/images. Set `video` or `media` on a project in content.js to replace its placeholder.
- `assets/` — résumé PDF
